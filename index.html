Server IP and how to join

Hop on Fractured

Join on Java or Bedrock, from a PC, phone, tablet or console. It takes about a minute to add the server.

Java Edition PC, Mac and Linux · Java 26.1.2

  1. Open Minecraft: Java Edition and click Multiplayer. If a warning pops up, click Proceed.
  2. Click Add Server.
  3. Type fracturedsmp.datho.st in the Server Address box and click Done.
  4. Click Fractured SMP in your server list, then click Join Server.

Rules, events and the crew live in the Discord. Join it before you hop on.

Bedrock Edition Phone, tablet and Windows

  1. Open Minecraft and tap Play, then open the Servers tab.
  2. Scroll to the bottom and tap Add Server.
  3. Type Fractured SMP as the name, fracturedsmp.datho.st as the Server Address and 17055 as the Port.
  4. Tap Save, then tap the server to join.

Xbox, PlayStation and Switch

Consoles can't type in a server address, so use the free BedrockTogether app on a phone that's on the same Wi-Fi as your console.

  1. Download BedrockTogether on your phone and open it.
  2. Type fracturedsmp.datho.st as the address and 17055 as the port, then start it.
  3. On your console, open Minecraft, go to Play and open the Friends tab.
  4. Join the game under LAN Games. Keep the app open until you're in.
